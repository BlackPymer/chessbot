# ChessBot

Шахматный бот на основе нейросети, играющий на Lichess. Бот использует 3D CNN, обученную на PGN-партиях, для предсказания ходов и играет через Lichess Board API. Включает систему автообучения, которая постепенно повышает уровень игры против Stockfish (уровни 1-8), обучаясь на своих проигрышах.

## Структура проекта

```
chessbot/
├── main.py                 # Точка входа — асинхронный игровой цикл и логика бота
├── autotrain.py            # Автообучение — игра, обучение на проигрышах, повышение уровня
├── converter.py            # Конвертация FEN в тензор и индексация UCI-ходов
├── network/                # Нейросеть
│   ├── net.py              # Архитектура 3D CNN (Conv3d → FC → 4672 хода)
│   ├── bot.py              # Обёртка для инференса (загрузка весов, вероятности ходов)
│   └── train.py            # Обучение на PGN-данных (синхронное + асинхронное)
├── game_services/          # Интеграция с платформами
│   ├── service.py          # Базовый интерфейс сервиса
│   ├── lichess/            # Интеграция с Lichess (Board API)
│   │   ├── client.py       # Низкоуровневый HTTP-клиент
│   │   └── service.py      # Высокоуровневый игровой сервис
│   └── chesscom/           # Интеграция с Chess.com (Playwright)
│       └── service.py
├── game_brain/             # Шахматная логика
│   ├── game.py             # Основной класс игры (python-chess)
│   └── client.py           # Обёртка для управления игрой
├── games/                  # Автосгенерированные PGN проигрышей по уровням Stockfish
└── requirements.txt
```

## Архитектура

### Нейросеть

Сеть (`network/net.py`) — 3D CNN, принимающая представление доски и выдающая вероятности для 4672 возможных ходов:

- **Вход**: тензор `(1, 17, 8, 8)` — 12 плоскостей фигур (6 белых + 6 чёрных), 4 плоскости прав на рокировку, 1 плоскость взятия на проходе
- **Слои**: 3x Conv3d + BatchNorm + MaxPool → FC(512) → Dropout(0.7) → FC(4672)
- **Выход**: распределение вероятностей по всем возможным UCI-ходам (64x64 базовых хода + превращения)

Конвертер (`converter.py`) отвечает за преобразование FEN → тензор и UCI-ход → индекс. При игре за чёрных доска и ходы отзеркаливаются на перспективу белых для сети.

### Игровой цикл

1. Создание игры против Stockfish AI через `/api/challenge/ai`
2. Стриминг состояния игры через `/api/board/game/stream/{id}`
3. Определение нашего цвета из события `gameFull` в стриме
4. На каждом ходу: FEN → тензор → вероятности ходов → маскировка нелегальных → сэмплирование хода → отправка через API
5. Возврат результата игры, ходов и PGN

Игровой цикл полностью асинхронный, что позволяет выполнять параллельные операции (например, обучение во время игр).

### Автообучение (`autotrain.py`)

Система прогрессивного обучения против Stockfish уровней 2-8:

1. Играем партии против текущего уровня Stockfish
2. При каждом проигрыше сохраняем PGN в `games/stockfish_level_N.pgn`
3. После накопления достаточного количества проигрышей (по умолчанию: 5) переобучаем сеть на:
   - Базовом PGN-файле (ваши партии, все ходы)
   - PGN проигрышей текущего уровня (только ходы победителя — учимся играть как соперник, который нас обыграл)
4. При выигрыше переходим на следующий уровень и сбрасываем счётчик
5. Файлы проигрышей предыдущих уровней больше не используются для обучения

Обучение работает параллельно с играми через asyncio.

### Интеграция с Lichess

Используется **Board API** (для бот-аккаунтов). Основные эндпоинты:
- `POST /api/challenge/ai` — начать игру против Stockfish (уровни 1-8)
- `GET /api/board/game/stream/{id}` — стрим событий игры
- `POST /api/board/game/{id}/move/{move}` — сделать ход

## Установка

```bash
python -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
```

## Конфигурация

Создайте файл `.env` в корне проекта:

```env
LICHESS_TOKEN=ваш_токен_lichess
```

### Получение токена Lichess

1. Перейдите на https://lichess.org/account/oauth/token
2. Создайте токен с правами: `board:play`, `challenge:read`, `challenge:write`

## Использование

### Одиночная игра

```bash
python main.py
```

Настройки в `main.py`:
- `OPPONENT` — `"stockfish"` или имя бота
- `STOCKFISH_LEVEL` — от 1 до 8
- `CLOCK_LIMIT` — время в секундах (минимум 480 для Board API)
- `COLOR` — `"white"`, `"black"` или `"random"`
- `WEIGHTS_FILE` — имя файла весов из `network/weights/`

### Автообучение против Stockfish

```bash
python autotrain.py
```

Настройки в `autotrain.py`:
- `START_LEVEL` — начальный уровень Stockfish (по умолчанию: 2)
- `MAX_LEVEL` — максимальный уровень (по умолчанию: 8)
- `MIN_LOSSES_TO_TRAIN` — количество проигрышей до переобучения (по умолчанию: 5)
- `RETRAIN_EPOCHES` — количество эпох за раунд обучения (по умолчанию: 20)
- `BASE_PGN` — базовый PGN-файл, всегда участвующий в обучении

### Ручное обучение на PGN-данных

```bash
python -m network.train
```

## Зависимости

- **python-chess** — шахматная логика и валидация ходов
- **torch** — нейросеть (3D CNN)
- **numpy** — операции с тензорами
- **requests** — HTTP-клиент для Lichess API
- **python-dotenv** — загрузка переменных окружения
- **playwright** — автоматизация браузера для Chess.com (опционально)
